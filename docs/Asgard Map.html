What Asgard could be

Four ways to describe the same pile of apps. They pull the work in different directions.

Lean: start here

A home hub for the family

One sign-in, files arrive where they belong, and everyone hears when something is ready. This is what the vision file already describes.

Pulls on: shared events and one sign-in.

Lean: build alongside

An internet-optional home

Everything useful works on the Wi-Fi alone. Share a photo phone to PC, play together, listen in sync, and pre-download before a trip.

Pulls on: finding the home server and pairing once, and offline-first clients.

Option for later

A subscription-replacement kit

Chat, media, files and games that live in your house, with no account on someone else's server. If another family could install it, Asgard becomes a product.

Pulls on: a one-command install, real docs, and two repos you don't own (Bragi, Tafl).

Option for later

One integrated stack, built by you

Identity, workflows, real-time chat and a download engine, working as a single system. The value is the engineering story more than the feature list.

Pulls on: polish, write-ups and a clean demo more than new features.

Ideas the vision file doesn't have yet

Each one reuses something already on the map, so it adds a feature without adding an app.

Gjallarhorn as a Huginn bot

System alerts arrive in the family chat as messages from a bot. That saves a whole app and keeps one place to look.

Reuses: Huginn, Sleipnir events.

Guest pass

Heimdall hands out a time-limited sign-in to visitors on your Wi-Fi, so a friend can join game night without an account.

Reuses: Heimdall, Tafl, local discovery.

Trip pack

One list on the phone of shows, maps and game packs. Sleipnir fetches all of it on home Wi-Fi the night before.

Reuses: Sleipnir scheduling, Tafl packs.

Hliðskjálf as a read-only feed

The home dashboard is a view over the same events everything else produces, not a separate monitoring stack.

Reuses: the shared event feed.

Muninn from the share sheet

Photo backup that rides on the phone-to-PC path from scenario 3. Share once, and it lands in the right folder.

Reuses: Sleipnir receiving files, pairing.

The smallest first link

Pick one link that proves the model before anything else. Sleipnir already leaves room for events, and Huginn already exists as somewhere to show them.

  1. Sleipnir sends a small "download finished" message when a file completes.
  2. Huginn accepts it through one webhook and posts it in a family channel.
  3. That is the first half of movie night, and it proves the event idea with two apps.
